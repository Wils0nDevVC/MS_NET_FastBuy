## **Instalación y primeros pasos**

1. **Clonar el repositorio**
   * Navega hasta la carpeta donde quieres guardar el proyecto clonado.
   * Pega la siguiente línea en la terminal, reemplazando la URL por la que copiaste:
     ```bash
     git clone [https://tu-url-aqui.git](https://tu-url-aqui.git)
     ```

2. **Ejecutar el comando `tu-comando`:**

     ```bash
     ls

     ```
